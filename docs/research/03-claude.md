# 参考视频 3：Claude 开机动画（要在此基础上改进的版本）

- 来源：https://www.bilibili.com/video/BV1i5JQ6WEGh/ （标题“claude开机动画”，UP 主：iI听枫，29.4 s，1728×1080 / 30 fps）
- 插件 GitHub：待用户提供
- 观看方式：18 fps 逐帧（529 帧）+ 关键帧全图 + 本地语音识别 / 声音分类
- 说明：时间都是视频时间。启动动画在视频里**播放了两次**：第一次在小窗口里（0.3 – 8.8 s），第二次全屏（10.0 – 17.2 s）。后面是聊天演示。

## 一、角色形象（新动画要沿用的部分）
- 橙色长发少女，琥珀色眼睛；头上有**橙色雏菊/太阳花发饰** + 黑色蝴蝶结 + 流苏。
- 米白色荷叶边上衣、披肩，黑色束腰，**橙色长飘带**，白色长裙，裙摆和袖口都有橙色花朵纹样。
- 怀里抱着一本**深棕色书**，封面上也是橙色花朵。
- 配色和 Claude 品牌非常吻合：橙（`#D97757` 一类的珊瑚橙）、米白、深棕/黑。
- 右下角有一个**圆形头像徽章**（角色的大头像，橙色描边）。
- 文字标识：`✱ Claude`（Claude 的星芒 logo + 衬线体字标）。

## 三、启动动画逐段细节（以全屏的第二次为准，10.0 – 17.2 s）

**背景与 HUD**
- 米白色背景，中间偏右有一团**淡淡的橙色光晕**（径向渐变）。
- 漂浮的**橙色小圆点粒子**（大小不一，有的在缓慢飘动）。
- 左上：一条橙色细线 + 等宽字体的“终端日志”逐行打出：
  `▸ CLAUDE · ……` / `▸ ……` / `▸ SESSION 0x2F · ……` / `▸ READY`
  **问题：中文部分显示成了方框 □□□（缺字体）**，只有英文能正常显示。
- 左下：`CLAUDE · WORKSPACE`（灰色等宽小字）。
- 右下：圆形角色头像徽章（全程都在）。

**1. 线稿描绘（10.8 – 12.0 s）**
- 10.8 s 起，角色的**橙色线稿从头部开始一块块出现**（头发、发饰、脸 → 书和手 → 身体 → 裙摆），像是被“涂”出来的，边缘有一点模糊/溶解的感觉。
- 线稿是单色橙，线条比较粗、有点像描边滤镜生成的。
- 约 1.2 s 画完全身。

**2. 上色（12.0 – 12.6 s）**
- 颜色从**上往下**铺开：头部先变成彩色插画，下半身还是线稿（12.3 s 时上半身彩色、下半身线稿，交界处有一条柔和的过渡带）。
- 约 0.6 s 完成。

**3. 标题（12.6 – 14.2 s）**
- 12.6 s：左侧出现橙色星芒 `✱`，先是淡粉色，然后变成实心橙色。
- 12.7 – 13.5 s：`Claude`（大号衬线体，深色）**逐字母出现**，每个新字母出现时有一点**故障/扭曲**的效果（字形先歪一下再归位）。
- 13.8 s 起：下方淡入“欢迎来到专业工作模式”（粗体）+ 橙色下划线 + `PROFESSIONAL WORK MODE`（橙色、宽字距）。
- 同时右侧有几条**橙色竖线**从上往下滑落（像雨丝 / 数据流）。

**4. 停留（14.2 – 17.2 s）**
- 画面基本不动：竖线继续落下，粒子漂浮。约 3 s。

**5. 交接（17.2 – 17.3 s）**
- 几乎是**硬切**到主界面（1–2 帧之内完成），左侧出现侧边栏，中间是 `✱ 有什么可以帮你的吗？` 和输入框，角色保持在右边当背景。

## 四、聊天界面里的额外效果（22 – 29.4 s）
- 发送消息后，标题和输入框滑到底部，角色**变回橙色线稿**，脸上叠加**三角网格**，背景出现**方格纸网格**，左上出现“✱ Claude 正在思考…”气泡——用“线稿化”表示“正在思考”，这个想法很好。
- 回复出来后，角色从线稿**重新上色**，回复卡片显示“已完成，用时 3 秒”。
- 右下角头像上方弹出一个思考气泡卡片：“上一轮对话用时 **3 秒** / Claude 已就绪”。
- 小问题：模型选择器 `Sonnet 5.5 ☒` 和卡片里也有方框字符（缺图标字体）。

## 五、声音
- 没有人声，全程背景音乐。声音分类结果偏 **disco / funk / dance pop**，轻快明亮。

## 六、为什么用户觉得它不如前两个精美（我的分析）

| 方面 | DeepSeek 版 | Codex 版 | Claude 版（现状） |
| --- | --- | --- | --- |
| 剧情 / 阶段 | 6 步授权，编号进度 | 3 阶段：WIREFRAME / MATERIALIZE / AWAKEN | 有“线稿→上色→标题”，但**没有阶段提示**，观众感觉不到“进度” |
| 背景的“活”元素 | 实时时钟、音频柱、十六进制滚动、旋转圆环、扫描光带 | 星尘、倾斜椭圆轨道 + 移动光点、网格球面 | 只有粒子和竖线，**比较空** |
| 线稿质感 | 发光线条一笔一笔“画”出来 | 青色发光线条从头顶“生长”下来 | 色块状出现，**像遮罩溶解，不像在画线**；线条偏粗、没有光 |
| 上色过渡 | 线稿上逐渐铺色 + 质感 | 冷色到暖色的显影 | 从上往下擦，时间很短（0.6 s） |
| 标题 | 描边 → 金属填充 + 光线扫过 + 星光 | 描边 → 白青渐变填充 | 逐字母 + 小故障，**没有光效** |
| 进度 / 跳过 | 底部刻度进度条、SKIP、Enter/Space | 进度条 + 百分比、ESC 跳过 | **没有进度条，也没有跳过提示** |
| 收尾交接 | 交叉叠化，视频变成背景，留下吉祥物 | 压暗后主界面浮出 | **硬切** |
| 细节 | 双语排版很讲究 | 极简但统一 | 中文 HUD 文字是方框（缺字体），很影响观感 |
| 镜头感 | 失焦、闪白、光带 | 镜头轻推、发丝摆动、眨眼 | 角色完全静止，**没有呼吸感** |

## 七、新版本的初步方向（待看完三个 GitHub 仓库后再定）
- 保留：这个角色、橙 / 米白 / 深棕配色、`✱ Claude` 衬线字标、右下角头像徽章、“思考时变线稿”的创意。
- 借鉴 DeepSeek：带编号的分步剧情（可以改成符合 Claude 风格的步骤，比如“唤醒 → 阅读上下文 → 整理思路 → 就绪”，和她手里的书呼应）、双语编辑式排版、实时时钟、底部刻度进度条、交叉叠化交接、留一个吉祥物。
- 借鉴 Codex：WIREFRAME / MATERIALIZE / AWAKEN 式阶段列表、真正“一笔一笔画出来”的发光线稿、椭圆轨道光点、标题描边→填充、ESC 跳过。
- Claude 特有的点缀（初步想法）：星芒 `✱` 可以作为“画笔”的笔尖沿着线稿移动；书页翻动 / 纸张纹理；雏菊花瓣代替普通粒子；整体是“暖色、纸张、手绘”的感觉，和前两个的冷色科技风区分开。
- 必修：中文字体（不能出现方框）、加入交接动画、加入跳过和进度。
