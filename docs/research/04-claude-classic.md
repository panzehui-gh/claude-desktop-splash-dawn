# 参考视频 4：Claude 开屏 classic ver.（新版 Claude 角色）

- 来源：https://www.bilibili.com/video/BV1rAsX6EEDC/ （标题“[Claude] 开屏classic ver.”，UP 主：努力在爬的咸鱼二世，14.2 s，1080p / 30 fps，2026-10-28）
- 代码：基于 Firefade0329/claude-desktop-splash（MIT）改的分支 https://github.com/Inanis404/claude-desktop-splash （v1.2.0），正在向原项目提 PR。
- 简介里列的改动：服饰改成 Claude 经典款式；清理了 AI 画图的杂乱碎发纹理；睁眼改成 Live2D 视频；加了开机音效和图标。
- 观看方式：18 fps 逐帧（256 帧）+ 关键帧全图。没有人声。

## 角色
- 和第 3 个视频是同一个角色（橙发、雏菊发饰、黑色蝴蝶结 + 金色流苏、白色荷叶边高领、黑色领巾、金边披肩），但这里是**胸像特写**，画得更精细，光感更好。
- 闭眼 → 睁眼，微笑，眼睛是琥珀色。
- 注意：这一版**没有抱书**（抱书的是第 3 个视频那张全身图，那个作者没有公开代码和图）。

## 时间线（视频时间）
| 时间 | 画面 |
| --- | --- |
| 0 – 0.5 s | 深蓝黑底，带一点星点 |
| 0.5 – 2.0 s | 两条**流光丝带**从左右两边飞进来：左边陶土橙、右边象牙白，前端是尖锐的亮点，后面拖着变宽的多层半透明带，边上有颗粒光点；两条在中间交叉，交叉处很亮 |
| 1.8 – 2.4 s | 又有杏色、奶油色的细丝带从边缘飞入 |
| 2.1 – 3.5 s | 丝带后面，角色的**发光橙色线稿**从头部向外一圈圈扩散出现（用的是径向遮罩，不是一笔一笔画）；线稿很密，像金色的电光 |
| 3.2 – 4.0 s | 眼睑和睫毛的线条**单独亮起**（比别处更亮，橙色发光的闭着的眼睛） |
| 3.5 – 4.6 s | 丝带往画面外流走、变淡，留下全屏的发光线稿 |
| 4.5 – 5.3 s | 背景从黑**变亮成天空灰白**，彩色的闭眼图从线稿里浮现；线稿还在上面，过一会儿才淡掉 |
| 5.3 – 7.3 s | 闭着眼的彩图，**头发、飘带、花瓣随风飘动**（Live2D），花瓣从画面里飘过 |
| 7.3 – 7.7 s | 睁开眼，带一点笑 |
| 7.6 – 8.9 s | 右上角：小字 `CLAUDE`，大标题“**Claude 启动……**”逐字打出（橙色竖光标），橙色细线伸出，下面“欢迎回来，**博士**”（“博士”是橙色） |
| 9.0 – 9.9 s | 整个画面压暗到黑（视频里是淡到黑；实际使用时是淡出露出 Claude 窗口） |
| 10.2 – 14.2 s | 片尾信息卡（不属于动画）：头像、“Claude 开屏动画”、GitHub 地址、“非官方个人项目，与 Anthropic 无关” |

## 和前面几个比
- **好的地方**：画最精致；流光丝带质感很好；“线稿 → 上色 → 睁眼”节奏顺；Live2D 让头发在动，比静止立绘活很多；有原创合成音效。
- **朴素的地方**（用户的感受）：
  - 只有一个镜头、一种构图，从头到尾是一张脸的特写，没有 DeepSeek 的“幕”和 Codex 的“故事”。
  - 线稿是**径向遮罩扩散**，不是“画出来”；上色也是整体淡入。
  - 文字只有一个标题 + 一句欢迎语，没有阶段感、没有进度。
  - 结尾是简单淡出，没有 Codex 那种“动画变成界面”的交接。
  - 没有 Claude 自己的符号（星芒 ✱）参与叙事。
