# 参考视频 2：Codex “白龙娘”启动动画

- 来源：https://www.bilibili.com/video/BV1WPHo6pEcj/ （标题“codex的启动变的有亿点点不一样？”，UP 主：雨刷啊，25.7 s，1080p / 30 fps，2026-10-05 上传）
- 简介里说想要的人多的话会整理发布，**目前可能还没有公开的 GitHub 地址**。
- 观看方式：18 fps 逐帧（463 帧）+ 启动窗口裁切放大的关键帧 + 本地语音识别 / 声音分类
- 说明：时间都是视频时间。视频里启动动画**放了两遍**：第一遍 1.7 – 15.5 s，第二遍从 20.6 s 开始（和第一遍一样，只录到一半），所以以第一遍为准。
- 之前看错的那个视频（BV1PSpY6tET6，银发龙娘、暗色青绿风）的笔记改名为 `99-codex-plain-version-not-reference.md`，不再作为参考。

## 一、整体印象
- **亮色、通透、梦幻**：白 / 银 / 淡紫 / 淡蓝，有天光、云海、镜面地面。和 DeepSeek 版第二幕的暗色霓虹完全相反。
- 角色是**白发龙娘**：龙角、淡紫色蝙蝠翼、龙尾、白色荷叶边长裙，裙子和发饰上都有 OpenAI 的花结 logo 纹样。
- 动画是一段**有镜头运动的“短片”**，不是静态立绘加特效：角色会动（睁眼、抬手、转身、飘起来），镜头会绕着她转。
- 整个过程讲了一个故事：**“点一下 → 召唤出龙娘 → 她施展魔法把工作区搭出来 → 工作区变成真正的 Codex 界面”**。

## 二、逐段细节

### 0 – 1.7 s：录屏开头
- 樱花桌面，从开始菜单点开 Codex（录屏部分，不属于动画）。

### 1.7 – 2.0 s：窗口出现
- 窗口先是白的，再**黑屏一下**（约 0.15 s），然后变成米白色。大小约占屏幕一半，居中。
- 右上角一直有一个很小的半透明按钮 **“跳过 Esc”**。

### 2.0 – 3.2 s：按钮 + 手
- 中间出现一颗胶囊形按钮 `codex start`（等宽字体，细描边），周围有几根**放射状的短线**（像漫画里的“强调线”），轻轻闪动。
- 2.2 s 起，一只**画出来的手**（白色荷叶边袖子，手腕挂着流苏）从右下角伸进来，食指慢慢靠近按钮。
- 2.8 s：手指按下，按钮**变灰、凹下去**，文字消失，像实体按钮被按下去一样（大约 0.3 s）。

### 3.2 – 4.3 s：按钮变 logo
- 被按下的按钮**旋转 / 形变**成一个黑色圆角方块，里面是 OpenAI 花结 logo（3.0 – 3.3 s，有一点残影模糊）。
- 手指停在 logo 旁边，然后**慢慢收回**（手指弯起来），像按完开关后把手拿开。
- 4.1 – 4.3 s：logo 变淡、开始发光。

### 4.3 – 5.3 s：爆光 + 召唤
- 4.3 s：logo 位置**爆出一团强光**，整个窗口几乎变成白色，四周有**放射状的光线**（速度线）向外冲。
- 4.5 s：光里浮现出龙娘的剪影，**身体是半透明的，边缘有金色的光**（像从光里“凝聚”出来），四周有一圈圈淡紫色的光环。
- 4.8 s：光慢慢退去，背景变成**天空 + 云海 + 镜面地面**，左上角有斜着照下来的**丁达尔光束**和镜头光斑。
- 5.0 s：裙摆和脚下的**金色光边**最后褪掉，角色完全显形。

### 5.3 – 7.0 s：苏醒
- 角色站在镜面地面上，背后的翅膀张开。
- 5.5 s：她**闭着眼睛，把手放到胸前**（像在祈祷 / 感受）。
- 6.7 s：她**睁开眼睛**，手前方飞出一道**白色光流**（像魔法），向左边划过去。
- 镜头这时开始**轻轻推近、绕转**。

### 7.0 – 10.5 s：搭建工作区（最华丽的一段）
- 7.0 s：光流划过的地方，左侧出现**巨大的 0 / 1 数字**（离镜头很近、有景深模糊），像漂浮在空中的二进制。
- 7.3 s：空中浮现**半透明的玻璃面板**：左边是一条竖排的图标栏（终端、`</>`、文件夹、运行、设置），右边是一个代码窗口，里面写着 `const workspace = compile(); await workspace.mount(); workspace.ready = true;`，底下还有 `workspace › ready` 的按钮。
- 7.8 s：底部出现一个命令行输入框 `> |`，有闪烁的光标。
- 7.8 – 8.8 s：龙娘**张开双臂飘起来**，周围的 **0 / 1 数字排成一条条“丝带”**，像银河一样绕着她旋转，丝带上带着金色的光。
- 8.8 – 10.4 s：镜头**绕着她转了一圈**：从正面 → 侧面 → **背面**（能看到长发、翅膀和龙尾）→ 另一侧 → 回到正面。数据丝带在她周围上下盘旋，地面上的倒影也跟着转。这一段很有 3D 感。

### 10.5 – 12.6 s：界面成形
- 10.8 s：从她身边飞出一块**倾斜的大玻璃面板**，在空中**旋转、摆正**，变成 **Codex 工作区界面**（侧边栏：新任务 / 项目 white-dragon-boot / 启动动画 / 角色与场景 / 最近：代码与界面、镜头与动作；右侧是“更改”面板，显示 `boot.tsx` 的代码 diff，一行行出现，有打字光标；底部有“描述你想构建的内容”输入框和“6 个组件已就绪”）。
- 龙娘**留在界面中间**，像是界面的一部分，还在轻轻飘动。
- 面板有玻璃质感：半透明、边缘发光、底下有阴影投在云海上。

### 12.6 – 14.2 s：“开始构建”
- 12.6 s：界面摆正、缩小一点，龙娘**变小并移到中间**，上方出现大字“**开始构建** / 让想法成为现实。”
- 13.3 – 14.2 s：龙娘**慢慢变淡**，最后只剩一个很淡的影子。
- 背景里有一条**细细的椭圆轨道**从界面后面穿过，上面有几个小圆点，两侧有竖排的 `0 1 0`。

### 14.2 – 15.5 s：光球交接
- 14.3 s：龙娘胸前的位置出现一个**淡紫色的光球**。
- 14.5 – 14.9 s：光球**迅速变大**（像气泡 / 能量球），把整个界面吞进去；球的边缘是紫色，中间是白色。
- 14.9 s：“开始构建”下面淡出 **“我们要构建什么？”**，并出现 Codex 的 logo——这已经是**真正的 Codex 主界面**的内容了。
- 15.0 – 15.4 s：动画界面和真实界面**叠在一起交叉淡化**，边缘还有一圈淡紫色的光，最后变成真正的 Codex 窗口（标题栏、文件 / 编辑 / 视图 / 帮助菜单、“我们要构建什么？”、GPT-6.1 Sol Ultra 模型选择）。
- 整个启动动画约 **13.5 秒**（1.9 – 15.4 s）。

## 三、声音
- 没有人声，全程背景音乐。开头偏轻快（分类模型认为有类似羽管键琴的音色），中段转成电子乐（electronica），召唤 / 旋转那段更有冲击感，结尾变得柔和（tender music）。具体乐器无法确定。

## 四、和另外两个视频的对比

| 方面 | DeepSeek Harness | Codex 白龙娘 | Claude（现状） |
| --- | --- | --- | --- |
| 时长 | 约 28 s | 约 13.5 s | 约 7 s |
| 叙事 | 6 步授权流程 | 点按钮 → 召唤 → 施法搭建 → 界面成形 | 线稿 → 上色 → 标题 |
| 角色表现 | 第二幕视频：线稿变插画、睁眼 | **全程在动**：祈祷、睁眼、施法、飞起、转身 360° | 静止立绘 |
| 镜头 | 基本固定 | **推近、环绕、景深** | 固定 |
| 和产品的关系 | 授权文案 + 品牌字 | **把 Codex 界面“搭”出来**，最后和真界面无缝衔接 | 结束时硬切到聊天界面 |
| 互动 | Enter / Space / SKIP | 一开始“按下”开关（演出），Esc 跳过 | 无 |
| 色调 | 亮色极简 → 暗色霓虹 | 亮色梦幻（白 / 银 / 淡紫 / 金光） | 米白 + 橙 |

## 五、值得借鉴的手法
1. **开场的“开关”**：一只手按下按钮，按钮变成 logo——用一个具体的动作代替“加载中”，非常有仪式感。
2. **光爆召唤**：强光 + 放射线 + 半透明身体 + 金色描边，角色是“被召唤出来”的。
3. **角色有动作**：闭眼祈祷 → 睁眼 → 施法 → 张开双臂 → 飞起，让人觉得她是活的。
4. **伪 3D 镜头环绕**：绕着角色转一圈，加上景深和地面倒影，层次感非常强（这部分很可能是用 AI 视频生成的素材，单纯用网页代码很难做到）。
5. **“她把工作区搭出来”**：漂浮的代码面板、0/1 数据丝带，最后飞出来的面板摆正成真实界面——动画内容和产品本身紧密相关。
6. **和真实界面无缝衔接**：动画里的界面和真实界面布局一致，最后用光球 + 叠化过渡，几乎看不出切换。
7. **克制的跳过按钮**：右上角小小的“跳过 Esc”，不打扰画面。
8. 亮色系也能做得很高级：靠**光**（丁达尔光束、镜头光斑、金色描边、光球）和**玻璃质感**来提升精致度。

## 六、对 Claude 版的启发
- Claude 版的角色抱着一本**书**，可以对应 Codex 版的“按钮 → logo”：**翻开书 → 书页里飞出光和文字 → 文字变成 Claude 的界面**。
- 星芒 `✱` 可以像 Codex 的 logo 一样作为“召唤”的媒介。
- 镜头环绕、角色转身这类效果需要视频素材（AI 生成或手绘动画），纯网页代码只能做到 2.5D（视差、缩放、遮罩）。具体能做到什么程度，要等看了插件源码再判断。
