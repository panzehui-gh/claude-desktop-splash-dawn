# Claude 启动动画 · 设计方案（草案，待确认）

## 一句话
在 claude-desktop-splash（及 Inanis 分支）的启动器和素材之上，**重写“演出”**：用 Claude 的星芒 ✱ 当“笔”，把角色一笔一笔画出来、用墨色晕染上色、让她在晨光里醒来，最后星芒化作一团暖光，把动画“交给”真正的 Claude 窗口。

主题词：**暖、纸、手绘、晨光**——和 DeepSeek 的冷色 FUI、Codex 的银白神殿明显区分开，符合 Claude 的品牌气质（陶土橙 / 象牙白 / 墨色）。

## 借鉴来源对照
| 手法 | 来自 | 在 Claude 版里的样子 |
| --- | --- | --- |
| 开场的“开关”动作 | Codex（手按按钮→logo） | 星芒 ✱ 自己一笔笔画出来，脉动一下，光芒伸长成流光丝带 |
| 分步叙事 + 编号进度 | DeepSeek（6 步授权）、Codex 旧版（WIREFRAME/MATERIALIZE/AWAKEN） | 左下角极简阶段条：`01 SKETCH 勾勒 · 02 INK 晕染 · 03 DAWN 醒来 · 04 READY 就绪`，下面一条细刻度进度线 |
| 活着的装饰元素 | DeepSeek（时钟、十六进制、圆环） | 实时时钟、缓慢旋转的细圆环（星芒的轨道）、少量“手稿批注”式小字（坐标、比例、色号），都用很淡的墨色，不抢角色 |
| 真正“画出来”的线稿 | Codex 旧版、DeepSeek 鲸鱼描边 | 把边缘检测的结果串成笔画，按离脸的远近排序，**由几个发光的笔尖沿线条走**，走过的地方留下发光的线 |
| 光效 | Codex（光爆、丁达尔光束、金色描边） | 天亮时左上角斜射晨光 + 柔和镜头光斑；上色完成时角色轮廓留一圈很淡的金边，再慢慢褪掉 |
| 镜头感 | Codex（推近、景深） | 2.5D：背景、角色、前景花瓣三层不同速度的轻微推近和视差；前景花瓣做景深模糊 |
| 标题 | DeepSeek（描边→金属填充+光线扫过） | `✱ Claude` 衬线字标：先描边写出，再填成象牙白→陶土橙渐变，一道光扫过 |
| 交接 | Codex（光球吞没→真界面） | 星芒在角色胸前的花饰处亮起，扩成一团暖光，盖满画面后淡出，露出 Claude 窗口 |
| 声音 | Inanis 分支（代码合成音效） | 沿用 `make_sound.py` 的思路，按新时间轴重新合成（笔尖沙沙声、晕染的柔和铺底、睁眼时的一声清亮音、交接时的上扬音） |

## 时间轴（约 11 秒，任何时刻点击可跳过）
| 时间 | 幕 | 画面 |
| --- | --- | --- |
| 0.0 – 1.2 | 序 · 星芒 | 墨蓝近黑的底，有一点纸张纹理。中央的 ✱ 一根根光芒依次画出，亮一下、轻轻脉动；HUD 淡入（时钟、阶段条） |
| 1.0 – 2.6 | 流光 | ✱ 的几根光芒伸长、甩出，变成原作那种多层流光丝带（保留并调色），从中央飞向四周 |
| 2.2 – 4.4 | 01 勾勒 | 丝带经过的地方留下光尘，光尘聚成笔尖；几个笔尖沿角色线稿“画”，先脸和头发，再衣领、花饰；眼睑最后、最亮。丝带向画外流走 |
| 4.2 – 5.8 | 02 晕染 | 颜色从胸前的雏菊花饰处**像水彩一样晕开**（噪声边缘，不是圆形遮罩）；同时背景由夜转为晨：星星淡去，左上斜射晨光；线稿慢慢退下，轮廓残留一圈淡金边 |
| 5.8 – 7.2 | 03 醒来 | 镜头极慢地推近；花瓣从前景飘过（景深模糊）；角色睁眼（经典版用光流睁眼，新版可用 Live2D 视频） |
| 7.0 – 8.8 | 04 就绪 | 右上角：小字 `CLAUDE`；`✱ Claude` 描边写出→填色→光线扫过；“欢迎回来，＿＿”逐字打出（称呼可配置）；阶段条走满，时钟旁出现 `READY` |
| 8.8 – 10.0 | 交接 | 胸前花饰处亮起一个 ✱，扩成暖光盖满画面，启动器同时把整个窗口淡出，露出 Claude |

## 技术方案
- **新项目 = 原项目的改写版**：复制 claude-desktop-splash 的 MIT 代码作为底座，保留 `launcher/`（只做必要的小改动），**重写 `splash.html`**，把新的演出模块分成几个 JS 文件，时间轴集中放在一个配置对象里，方便调节奏。
- **素材不复制**：角色图、Live2D 视频、图标都从你本机的原仓库（Inanis404 或 Firefade0329 的克隆）读取，新项目里只放一个路径配置。这样代码可以公开分享，图片的版权问题留给原作者。
- **纯网页实现**：Canvas 2D 为主；墨色晕染用噪声阈值遮罩；笔画追踪在加载时预计算（按需缓存），播放时只做绘制，保证流畅。需要的话可以加 `?t=3.2` 定格、`?speed=0.5` 慢放这样的调试参数（原项目已有类似的）。
- **降级**：页面没准备好、视频没载入、声音没解码好时都有退路（沿用原项目的做法）；系统开了“减少动画”时自动缩短。
- **README** 按你的习惯写英文 / 日文 / 中文三份，注明改写自哪个项目、改了什么，以及图片许可。

## 我能验证、不能验证的
- 能：在内置浏览器里直接打开 `splash.html` 逐帧预览、截图给你看，调到满意。
- 不能：完整的“双击快捷方式 → 动画盖在 Claude 窗口上 → 淡出”流程要在你的电脑上实际跑一次才能确认；我会把这一步写进说明，并如实标注哪些还没在真机上测过。
