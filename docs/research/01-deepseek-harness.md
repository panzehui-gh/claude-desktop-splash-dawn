# 参考视频 1：DeepSeek Harness 启动动画（dsh-boot-suite）

- 来源：https://www.bilibili.com/video/BV1wspE6EE8b/ （UP 主：人类与AI的日常，时长 36.1 s，1080p）
- 插件：https://github.com/LeeRolling/dsh-boot-suite （MIT）
- 观看方式：18 fps 逐帧（650 帧）+ 关键帧 1080p 全图 + 本地语音识别和声音分类
- 说明：时间都是视频时间（秒 + 帧/18）。文字内容和画面描述来自实际看到的帧；语音是机器听写的结果。

## 一、整体结构（三段式）

| 段落 | 时间 | 风格 | 作用 |
| --- | --- | --- | --- |
| 序幕 | 0 – 6.0 s | 黑底，品牌 logo 淡入淡出 | 程序启动、品牌出场 |
| 第一幕 | 6.0 – 25.6 s | **米白色 / 极简 / 编辑排版式 HUD** | 6 步“授权”剧情，有可交互按钮 |
| 第二幕 | 25.6 – 32.5 s | **深色 / 赛博朋克 / 发光线稿 → 实拍质感插画** | 全屏视频（UP 主自己超分过的素材） |
| 交接 | 32.5 – 34.5 s | 交叉叠化 | 视频淡成半透明背景，聊天界面浮上来 |

关键：**亮 → 暗** 的反差。第一幕冷静、克制、像一份印刷品；第二幕突然转暗、转成霓虹线条，情绪抬升。

## 二、逐段细节

### 序幕（0 – 6 s）
- 0.5–2.4 s：Windows 开始菜单滑上来，点开程序，开始菜单收回（这是录屏，不是动画本身）。
- 2.5 s：出现一个几乎全黑的无边框窗口，只有右上角的最小化 / 最大化 / 关闭按钮，窗口有一圈细细的蓝色描边。
- 3.3–4.0 s：鲸鱼 logo + “深度求索 / DEEPSEEK / DEEPSEEK HARNESS” 从 0 **淡入**（约 0.7 s）。
- 4.7–5.3 s：一道**竖向柔光**从左往右扫过 logo（像镜面反光 / 光带扫过）。
- 5.4–6.0 s：logo 淡出，同时背景从黑 **渐亮** 成灰、再到米白（约 1 s 的亮度过渡，不是硬切）。

### 第一幕：6 步授权流程（6 – 25.6 s）

**固定版式（整幕都在）**
- 背景：米白 `#EDEDE8` 左右，带几根**半透明竖条**（像玻璃柱 / 百叶窗的光影），营造纵深。
- 左上：大号粗体 `DEEPSEEK`（字母有故障效果的切片）/ `SYNTHESIZE INTELLIGENCE` / `HARNESS OS`。
- 左上小字：`REV 0.1.0 · WEB PROFILE` + **橙色实时时钟** `18:29:25`（每秒跳动）。
- 下面是 **6 段短横线进度**，当前步骤那一段是橙色。
- 右上：`SKIP ▸`。
- 左下：`[ 01 / 06 ] AUTHORIZATION` 步骤编号 + 一个**橙色小音频柱状图**（随声音跳动）。
- 右下：`· ID CONFIRMED : 12710`、`POWERED BY DEEPSEEK ▬`。
- 底部中央：一行中文状态 + 一行字距很宽的英文小字（如“等待用户授权… / AWAITING OPERATOR CONSENT”）。
- 最底部：一条**带刻度的细进度条**，整个流程中从左往右推进。
- 四角有细细的 L 形取景框角标。

**排版语言**：中文大字 + 下面一行**极宽字距**的英文等宽小字 + 一条细分隔线；整体是黑 / 灰 / 米白，**唯一强调色是橙色**（时钟、当前步骤、光标块、小圆点），后期再加一点蓝。

**6 个步骤**（中文标题都是**逐字打出**，后面跟一个**闪烁的橙色光标块** `▬`）：

1. **01 AUTHORIZATION · 需要访问许可 / ACCESS PERMISSION REQUIRED**（6.7–11.3 s）
   - 7.3 s 起标题逐字出现，英文小字同步逐字母出现，后面字母先模糊再变清楚。
   - 按钮 `授予访问权限 GRANT ACCESS`（细黑框），下面提示“按 Enter / Space，或点击按钮继续”。
   - 7.8–9.5 s：一条**横向亮带（扫描线）从上往下扫过**整个窗口，带一点阴影，像复印机扫描。
   - 9.6 s：按钮被“按下”，淡出（交互触发）。
   - 语音 7.0 s：“Access Permission Required.”
2. **02 IDENTITY · 身份资料确认 / IDENTITY VERIFICATION**（11.3–15 s）
   - 旧标题淡出 → 新标题逐字打出。
   - 出现一张**信息表**：身份名称 = 人类与AI的日常、身份编号 = 12710、权限等级 = 99（左灰标签，右粗体值，细线分隔）。
   - 按钮 `确认身份 CONFIRM IDENTITY`，13.6 s 被按下并淡出。
   - 底部：“核对身份资料… / MATCHING OPERATOR RECORD”。
   - 语音 11.3 s：“Identity Verification.”
3. **03 REQUEST · 接收访问需求 / ACCESS REQUEST RECEIVED**（15–16.7 s）
   - 标题逐字出现；下面的鲸鱼 logo 先是**线稿描边一笔一笔画出来**（15.3–16.6 s），再**填充成实心黑色**（16.6 s）。
   - logo 下方 `D E E P S E E K` 宽字距 + 一排 `- - - - - - - -` 虚线（像加载格）。
   - 底部：“接收访问需求，建立会话通道… / HANDSHAKE ESTABLISHED”。
   - 语音 14.8 s：“Access Request Received.”
4. **04 READ · 开始读取权限 / PERMISSION READ ...**（16.8–18.1 s）
   - 标题逐字出现。
   - 右侧淡入一块**十六进制数据矩阵**（`51 88 7D DF 09 3F …`），数字不停滚动刷新，上下两行半透明。
   - 底部：“开始读取权限，索引工作区与会话… / READING PERMISSION SET”。
   - 语音 16.8 s：“Beginning Permission Read.”
5. **05 VERIFY · 读取完毕 · 核验通过 / READ COMPLETE · VERIFIED**（18.1–21.5 s）← 视觉高潮
   - 18.2 s：标题消失，鲸鱼 logo 缩小居中。
   - 18.3–18.9 s：**巨大的同心圆环**从淡灰色**画出来**并逐渐变黑：
     - 外环：粗黑弧线，约 300°，末端有一个实心圆点（像进度条的头）。
     - 中环：白色发光细弧（在米白底上像高光）。
     - 内环：细黑线，上下两段弧。
     - 三个**橙色小圆点**分布在环之间。
   - 圆环**持续旋转**（外环末端圆点 18.6 s 在右上 → 20.5 s 在右下 → 21.3 s 在正下，约 3 s 转大半圈）。
   - 标题“读取完毕 · 核验通过”打在圆环中间，横穿整个圆。
   - 语音 18.6 s：“Complete.”，19.6 s：“Verification Passed.”
   - 21.3–21.9 s：圆环**由黑褪成灰再消失**（整体淡出，不是缩小）。
6. **06 WELCOME**（21.9–25.6 s）
   - 21.9–22.4 s：`WELCOME TO`（粗体宽字距）+ `DEEPSEEK HARNESS`（**黑底白字反白条**）+ 鲸鱼 logo **从模糊淡入到清晰**。
   - 下面 `D E E P S E E K · H A R N E S S` + “欢迎 人类与AI的日常 访问”。
   - 22.9 s：`WELCOME TO` 和中文欢迎语**变成蓝色**（`#2F6FB5` 左右），logo 加上柔和的投影。
   - 23.2–23.5 s：整个画面**泛白闪一下**（过曝闪光），然后恢复——像“确认”的那一下。
   - 底部：“身份验证完成，会话已建立 / IDENTITY VERIFIED · SESSION ESTABLISHED”，最底部进度条走满。
   - 语音 21.5 s：“Welcome to DeepSeek Harness.”

### 第二幕：赛博朋克视频（25.6 – 32.5 s）
- 25.6–26.0 s：第一幕整体**变暗 + 模糊**（像镜头失焦），同时上面开始出现**发光的青蓝色线条**，从右侧飞进来。两层画面叠在一起约 0.5 s。
- 26.0–27.0 s：线条越来越多，组成一个**发光线稿的少女侧脸**（头发、蝴蝶结、发饰），像是一笔一笔“画出来”的。
- 27.0–27.8 s：线稿上**逐渐铺上颜色和质感**，变成精细的 3D 插画（蓝发、女仆发饰、闭着的眼睛、脸上有网格线）。
- 27.8–29.0 s：左侧中间一道**横向光线扫过**，`DeepSeek` 大字**逐字母出现**（先是空心描边，再填充成金属银色、带蓝色光晕），右上有一颗小星星闪光。
- 28.4 s 起：女孩**睁开眼睛**，瞳孔里是**绿色滚动代码**。
- 28.4–29.5 s：副标题“欢迎来到专业工作模式 / PROFESSIONAL WORK MODE”淡入。
- 28.5 s 起：左下是终端风格的打字：`> initializing deepseek...` → `> loading model...` → `> ready`，带青色光标块。
- 四周有 HUD 装饰：左上 `Deepseek / AI ASSISTANT / FOR A BETTER TOMORROW`、左下 `AI COMPANION / SMARTER FUTURE`、右下 `//////` 斜纹、几条细线 + “+”号。
- 29.5–32.5 s：画面基本静止，只有细微的光效呼吸。

### 交接到聊天界面（32.5 – 34.5 s）
- 32.6 s 起：聊天界面（侧边栏、消息、输入框）**半透明淡入**，叠在视频上面。
- 33.0 s：右下角出现一个 **Q 版女仆小人**（和第二幕的女孩是同一个角色）。
- 33.0–34.0 s：视频逐渐变暗变淡，**最后留下来当聊天背景**（大约 30% 亮度），DeepSeek 大字和女孩的眼睛在背景里还能隐约看到。
- 全程没有黑屏、没有硬切。

### 结尾彩蛋（35.6 – 36.1 s）
- Q 版小人头上**冒出一个思考泡泡**（从小灰点 → 变大 → 变成白色气泡），里面显示 “DeepSeek 余额 ¥14.02 / 今日已用 ¥7.83 / 14:30:07”。也就是说，这个吉祥物还能当一个余额提示小部件。

## 三、声音
- 0–6 s 基本没有声音。
- 6 s 起有背景音乐；7–24.5 s 有一个英文 AI 女声/男声播报（7 句，和 6 个步骤一一对应，每句都卡在标题出现的那一刻）。
- 26 s 进入第二幕后，音乐变得更饱满（声音分类模型认为是带拨弦乐器的配乐，具体乐器无法确定）。

## 四、为什么它显得“精美”——可以借鉴的手法

1. **叙事感**：不是单纯放个 logo，而是“授权 → 身份 → 握手 → 读取 → 核验 → 欢迎”一个小剧情，每步都有编号 `[01/06]` 和进度。
2. **双语排版**：大号中文 + 宽字距英文小字 + 细线，像杂志/工业设计海报。
3. **克制的配色**：黑白灰 + 唯一的橙色点缀，最后才“解锁”蓝色，颜色的变化本身就是剧情。
4. **持续存在的“活”元素**：实时时钟、音频柱、滚动的十六进制、旋转圆环——画面静的时候也有东西在动。
5. **各种“揭示”动画**：逐字打字 + 光标、字母从模糊变清晰、logo 先描边后填充、扫描光带、圆环从淡到浓、光线扫过文字。
6. **可交互**：按钮可以按 Enter / Space / 点击；右上角可以 SKIP。
7. **反差转场**：亮色极简 → 暗色霓虹；用失焦 + 线条入场来过渡，不是硬切。
8. **无缝交接**：动画最后不消失，而是变成聊天界面的背景，并留下一个吉祥物。
9. **配音和画面严格同步**：每一句播报都对准一个标题出现的瞬间。

## 五、做 Claude 版时要注意的
- DeepSeek 的品牌元素（鲸鱼 logo、DEEPSEEK 字样、“深度求索”）只是参考，Claude 版要换成 Claude 自己的形象和文字。
- 第一幕是 HTML/CSS 动画（能交互、有实时时钟）；第二幕是一段视频素材。Claude 版也可以沿用这种“代码动画 + 视频”的组合。
