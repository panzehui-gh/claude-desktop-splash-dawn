# 三个仓库的代码阅读笔记

只读了代码，没有在本机安装或运行任何东西。仓库克隆在系统临时目录里，用完可以删。

## 1. LeeRolling/dsh-boot-suite（DeepSeek Harness，MIT）
- **形式**：DSH 插件。动画是**纯代码**（DOM + CSS 动画 + WebAudio），`lib/splash.js` 约 3300 行 + `lib/splash.css` 约 1400 行，没有视频或序列帧（第二幕的“鲸鱼娘”视频是另外的可选素材）。
- **分幕是数据**（v2.2.0 起）：每一幕的文案、按钮、时长写在模板里，1~24 幕都行。34 项可调（名字、编号、配色、速度、音色……）。
- 能学的技术点：
  - `typeIn`：逐字打出，每个字是一个 span，带错开的延迟。
  - `startHex` / `paintClock` / `setProgress` / `setSlats` / `sweep`：十六进制滚动、实时时钟、刻度进度条、百叶窗光影、扫描光带——都是独立的小模块，可以按需开关。
  - 环形准星（`arc()` 画多层 SVG 弧线）。
  - 转场系统 `trans*`：dissolve / 方向擦除等，带 reduced-motion 降级。
  - 声音：真人台词 mp3 +「语音没播完就不推进下一步」；另有 WebAudio 合成的界面音（`tone` / `noise`）和底噪。
  - `waitAction`：需要用户按 Enter / 空格 / 点击才继续的“交互关卡”。
- 设计文档 `docs/FUI-五要素.md` 很有用：**闪 / 故障、受限色盘（一主一副一中性）、暗底亮字、有节奏地依次登场、装饰信息**。
- 和 Claude 无关的部分（插件安装、DSH 配置）用不上。

## 2. yushua0808-cpu/dragon-codex-boot（Codex，代码 MIT；视频另有说明）
- **形式**：一个 C#/WPF 写的独立播放器（`src/DragonCodexBoot.cs`，约 450 行）+ 一段 14 秒 1080p 视频 `media/startup.mp4`。**动画本身全部在视频里**（AI 生成的龙娘、镜头环绕都是视频），代码只负责播放和交接。
- 最值得学的是**交接**：
  - 播放的同时启动 Codex；Codex 还没出来时，在视频的“等待节点”（11.3 s）停住等待。
  - 用 **Windows DWM 实时缩略图**把真实 Codex 窗口的画面嵌到视频里那块“屏幕”的位置（按关键帧插值它的矩形），随着动画里的屏幕放大，真实界面逐渐显现，最后撤掉播放窗口——所以看起来是“动画变成了界面”。
  - DWM 失败时退回普通淡出。
  - 首次运行会替换 Codex 的快捷方式（有备份和恢复脚本）。
- 视频的许可：随仓库分发，但 MIT 不覆盖视频，**不能把素材抽出来用在别的作品里**。

## 3. Firefade0329/claude-desktop-splash（Claude，代码 MIT；图片不在 MIT 范围内）
- **形式**：`splash.html`（Canvas 动画，约 51 KB）+ `launcher/launch.ps1`（PowerShell + 内嵌 C#）。启动器用 Edge 的 `--app` 模式打开网页，把窗口精确盖在 Claude 窗口上，同时启动 Claude，播完让窗口淡出。
- 动画由四层画布 + HTML 文字组成，时间轴集中在 `T = {...}` 里，很好改：
  - **流光丝带**（`RIBBONS`）：Catmull-Rom 曲线 + 多层半透明带 + 亮芯 + 边缘颗粒光点，五条丝带各有出场、摆动和退场参数。
  - **线稿**（`buildLineart`）：运行时对闭眼底图做 Sobel 边缘检测（亮度和饱和度两路），着色成橙色，再叠两层模糊做发光；眼睛那部分单独拆一层，晚一点亮起。出现方式是 CSS 径向遮罩从脸部向外扩散。
  - **上色**：闭眼彩图淡入 + 同样的径向扩散。
  - **睁眼**（经典版）：只换两只眼睛的小窗口，“上睫毛带”像刚体一样上滑，眼睑下面的眼珠用**光流**（Horn–Schunck 金字塔）做平滑过渡——这一段写得很用心。
  - **氛围**：星点、流光头部的光尘、花瓣（呼应发饰）、小星芒。
  - **文字**：右上角，逐字打出 + 橙色光标 + 橙线 + 欢迎语。
- 启动器的细节都考虑到了：页面没准备好就放弃动画、Claude 已在运行时不播、单实例、跟随 Claude 窗口位置缩放、只有点击可靠跳过（按键会被 Claude 收走）。
- 在 Windows 11 + Store 版 Claude 上由作者实测。
- **许可（重要）**：代码 MIT；`assets/` 里的角色图（AI 生成）**不在 MIT 范围内**，README 写明“在本项目之外使用这些图片，请先联系作者”。

## 3b. Inanis404/claude-desktop-splash（第 4 个视频，上面那个的分支，v1.2.0）
- 换了新角色图（经典款服饰），睁眼改成 5 秒 Live2D 视频（4K60 / 1080p60，按屏幕选），加了用 `tools/make_sound.py` **代码合成的开屏音效**（MIT），原图保留为 `?art=classic`。
- 新图、Live2D 视频、图标同样**不在 MIT 范围内**；合成音效按 MIT。

## 对 Claude 版的结论
- **底座**直接用 claude-desktop-splash（或 Inanis 分支）的代码：启动器已经在 Windows 上被实测过，覆盖 Claude 窗口、淡出交接这些难的部分都做好了，我们只需要重写 `splash.html` 的“演出”。
- **视觉素材只能用现有的角色图**：我没有办法自己画新的角色图或生成视频。所以“更精美”要靠**代码演出**来提升（镜头、光效、笔触、排版、节奏、声音），不是换画。
- **图片许可**：新项目不应该把作者的角色图复制进来再分发。建议新项目在运行时**引用你本机上原仓库里的素材**（安装时指向原仓库的 `assets/`），代码部分按 MIT 注明出处。这样你自己用完全没问题；以后想公开分享时，代码可以直接发，图片部分让对方自己去原仓库取，或者先征得作者同意。
