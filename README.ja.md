# Claude Desktop Splash · Dawn（夜明け）

Windows 版 Claude デスクトップアプリ用の起動アニメーションです。ショートカットをダブルクリックすると、Claude のウィンドウの上でアニメーションが再生され、その間に Claude がバックグラウンドで起動します。再生が終わるとフェードアウトして Claude が現れます。

> 非公式の個人プロジェクトで、Anthropic とは関係ありません。Windows 専用です。Microsoft Edge と Microsoft Store 版の Claude デスクトップアプリが必要です。画面上の文字は中国語です。

## 元のプロジェクトと変更点

このプロジェクトは [Firefade0329/claude-desktop-splash](https://github.com/Firefade0329/claude-desktop-splash) と、そのフォーク [Inanis404/claude-desktop-splash](https://github.com/Inanis404/claude-desktop-splash)（v1.2.0、MIT）を書き直したものです。元のプロジェクトには手を加えず、別のプロジェクトとして作っています。

- **ランチャー**（`launcher\`）：ほぼ元のままです。Claude のウィンドウを覆い、ウィンドウに追従し、フェードアウトで引き渡す部分は、元の作者が Windows で実際に確認済みです。変更したのは、ショートカットの既定の名前と、`-Art` を指定しないときに `config.js` の設定を使うようにした点だけです。
- **アニメーション**（`splash.html`、`js\`）：「夜明け」をテーマに作り直しました。DeepSeek Harness の起動スイートと Codex の竜娘起動アニメーションの手法を参考にしています。
  1. **序・星芒**：Claude の星芒 ✱ が一本ずつ描かれ、脈打ってから光の輪となって弾けます。
  2. **流れる光**：元のプロジェクトの光のリボンをそのまま使っています。
  3. **01 線描**：光るペン先がいくつも線に沿って動き、キャラクターを「描いて」いきます。目は最後に光ります（元は円形のマスクが広がる方式）。
  4. **02 にじみ**：胸元のデイジーの飾りから、水彩のように色が広がります。同時に夜が朝へ変わり、左上から朝の光が斜めに差し込みます。
  5. **03 目覚め**：一陣の風が吹き、カメラのすぐ前を大きな花びらが横切って、一瞬だけ画面の一部を隠します。カメラがゆっくり寄り、彼女が目を開けます。既定では元の Live2D 動画を使い（画質を選べます）、色が広がり始めてから最後まで一続きのアニメーションになります（約 7 秒から少しずつスローモーションになります）。髪やリボンが風になびき、一度まばたきします。途中で静止画に切り替わることはありません。Live2D をオフにすると、キャラクターは 1 枚の静止画になり、目を開けてまばたきするだけです（毛先を軽くそよがせることもできます）。いちばん軽いモードです。
  6. **04 準備完了**：`✱ Claude` のロゴが輪郭から描かれ、塗られ、光が横切ります。歓迎の言葉が一文字ずつ表示されます。
  7. **声**：音楽が落ち着いたあと、やさしい少女の声で “Welcome back, my dear friend.” と語りかけ、同じ言葉がタイトルの下に表示されます。話しているあいだ口は動きません。口の動き（元の絵の唇の線を Live2D のメッシュのように開き、あごも動かす）も試しましたが、元の絵の口はもともと 2 本の離れた線で、それが彼女の魅力の一つでもあります。口を開くとどうしても口が突然現れたように見えるため、やめました。口が動かないことに違和感があれば、設定で声をオフにできます。
  8. **引き渡し**：言葉が終わるころ、胸元の飾りに星芒が灯り、暖かい光となって画面を満たします。そのあとランチャーがウィンドウをフェードアウトさせます。全体で約 13 秒です。
  - 全体を通して、左上にリアルタイムの時計、左下に段階バー（01 線描 / 02 にじみ / 03 目覚め / 04 準備完了）と目盛り付きの進行線が表示されます。
  - 効果音：Web Audio でその場で合成しています（`js\sound.js`）。画面のタイムラインに合わせてあり、音声ファイルは使っていません。
  - 声：`tools\make-voice.py` が Microsoft のニューラル音声（edge-tts）で作ります。声の種類、速さ、高さ、セリフを変えられます。
- **設定ページ**：初回起動時に設定ページが開き、呼び名の入力、最後の声の試聴と選択、音量の調整、キャラクター画像の選択、アニメーションのプレビューができます。あとからも `--settings` でいつでも開けます。ダウンロードした人も自分の呼び名に変えられます。

## キャラクター画像について（重要）

キャラクター画像、Live2D の目を開ける動画、アイコンは元の作者のもので、**MIT ライセンスの対象外**です。そのため、このリポジトリには入っていません。`tools\get-art.ps1` が元のプロジェクトを `third_party\` にダウンロードし、アニメーションはそこから読み込みます。自分のパソコンで使う分には問題ありません。ほかの場所で使う場合は、先に元の作者に連絡してください。

## インストール

### かんたんな方法：Claude にインストールしてもらう

**Claude Code**（Claude デスクトップアプリの Code タブ）を使っている場合は、下の文章をコピーして Claude に送るだけで、この README に従ってすべてインストールしてくれます。（通常の Claude のチャットはパソコン上でコマンドを実行できないため、この方法は使えません。）

```text
この Windows パソコンに Claude Desktop Splash · Dawn（Claude デスクトップアプリの起動アニメーション）をインストールしてください：https://github.com/panzehui-gh/claude-desktop-splash-dawn

リポジトリの README の「インストール」の節に従ってください。要点：

1. リポジトリを「ドキュメント」フォルダの中の claude-desktop-splash-dawn というフォルダに置いてください（git があれば clone、なければ ZIP をダウンロードして展開）。このフォルダはあとから移動しないでください。
2. tools\get-art.ps1 を実行して、元の作者のキャラクター画像と Live2D 動画をダウンロードしてください。
3. Python と ffmpeg が入っているか確認し、足りないものは winget でインストールしてください（インストールの前に私に確認してください）。そのあと「py -m pip install edge-tts」「py tools\make-voice.py」「py tools\make-video-variants.py」を実行してください。最後のものは数分かかるので、バックグラウンドで実行してかまいません。
4. launcher\make_shortcut.ps1 と tools\build-exe.ps1 を実行して「Claude (Dawn).exe」を作ってください。
5. 「Claude (Dawn).exe」へのデスクトップのショートカットを 2 つ作ってください。1 つは「Claude (Dawn)」、もう 1 つは「Claude (Dawn) 設定」という名前で、リンク先の最後に「 --settings」を付けてください。ウイルス対策ソフトがショートカットを削除した場合は教えてください。
6. Claude を代わりに終了したり再起動したりしないでください。すべて終わったら試し方を教えてください：Claude を完全に終了し（タスクトレイのアイコンを右クリック → 終了）、「Claude (Dawn)」をダブルクリックします。初回は設定ページが開くので、呼び名・声・画質は私が自分で選びます。

各スクリプトを実行する前に、何をするのか目を通してください。失敗した手順があれば、黙って飛ばさずに理由を教えてください。
```

最後の手順の前で Claude が止まるのは意図的です。Claude Code は Claude デスクトップアプリの中で動いているので、Claude を終了するとその会話も終わってしまいます。試すのはご自身で、呼び名・声・画質も設定ページでご自身で選んでください。

### 手作業でインストールする

1. このリポジトリを決まった場所に置きます（デスクトップのショートカットがパスを覚えるので、あとで移動しないでください）。
2. キャラクター画像をダウンロードします：
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\get-art.ps1
   ```
3. 最後の声を作ります（インターネット接続が必要です。この手順を省くと声は入りません）。`tools\voices.json` にある 10 種類の声を作り（既定はイギリス英語の Sonia）、あとで設定ページで聞き比べて選びます：
   ```powershell
   py -m pip install edge-tts
   py tools\make-voice.py
   ```
   セリフを変えるには：`py tools\make-voice.py --text "Welcome home, my dear friend."`。ほかの声を加えるには、`tools\voices.json` に 1 行追加します（`--list` で使える声の一覧を表示）。
4. 目を開ける動画の各画質を作ります（ffmpeg が必要です。この手順を省くとコマごとの合成で目を開けます）：
   ```powershell
   py tools\make-video-variants.py
   ```
   元の 4K 動画から 8 種類の画質（B フレームなし、キーフレーム多め。内蔵 GPU でも滑らかにデコードできます）を作り、長さを 5 秒から約 8.5 秒に延ばして、アニメーション全体をカバーします。目を開けたあとは少しずつスローモーション（0.36 倍）になり、最後まで動き続けます。彼女が話すあいだ時間がゆっくり流れるような演出です。遅くなる部分には本物の中間コマを補っている（動き補償フレーム補間）ので滑らかです。元の動画ではキャラクターは 1 秒に約 30 ポーズしか変わらない（毎コマ動いているのは葉だけ）ため、ポーズが変わったコマだけを均等な時間間隔に並べ直してから中間コマを作ります。そうしないと同じポーズの繰り返しがスローで短い停止になり、カクカク動いて見えます。さらに、2 つのポーズのちょうど中間に補ったコマはポーズ上のコマより少しぼやけるため、画面が 1 秒に約 10 回「くっきり・ぼんやり」と脈打っていました。今はコマごとにポーズへの近さに応じてわずかにぼかし、すべてのコマが同じくっきりさになるようにしています。また、画面は常に前に進みます（以前の版は最後を逆再生していたため、舞い落ちる葉がはっきり逆向きに飛んでいました）。数分かかります。スローモーションの元動画は `assets\video\_master.mp4` に残します。
5. 起動用プログラムを作ります。1 行目で Claude のアプリ ID を調べてアイコンを取り出し、2 行目で Windows に付属の C# コンパイラーを使って `Claude (Dawn).exe` を作ります：
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\launcher\make_shortcut.ps1
   powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\build-exe.ps1
   ```
6. `Claude (Dawn).exe` をダブルクリックします。**初回はまず設定ページが開きます**。呼び名を入力し、声を聞き比べて選んでから「保存并启动 Claude」（保存して Claude を起動）を押します。
7. `Claude (Dawn).exe` を右クリック → 送る → デスクトップ（ショートカットを作成）を選び、以降はデスクトップから Claude を開きます。設定を変えたいときは、もう 1 つショートカットを作り、「リンク先」の末尾に ` --settings` を付けます（名前は「Claude (Dawn) 設定」など）。

Claude がすでに動いているときはアニメーションは再生されません。もう一度見るには、タスクトレイのアイコンを右クリックして Claude を完全に終了してください。

> .exe を使う理由：`make_shortcut.ps1` が作る `.lnk` は `conhost --headless powershell -ExecutionPolicy Bypass` を指しているため、ウイルス対策ソフトによってはマルウェアとして削除されます。`Claude (Dawn).exe` がするのは、ウィンドウを出さずに `launcher\launch.ps1` を実行すること、このパソコンの中だけの小さなサーバーでアニメーションと設定ページを提供すること（下記）、設定ページを表示することの 3 つだけです。ソースは `launcher\ClaudeDawn.cs` にあるので、中身を確認できます。

Claude を起動せずにアニメーションだけ見たいときは、設定ページの「预览动画」（プレビュー）を押すか、`preview.cmd` をダブルクリックします（`Claude (Dawn).exe --preview` を実行します）。

## 設定ページ

`Claude (Dawn).exe --settings` で設定ウィンドウが開きます（初回は自動で開きます）。`Claude (Dawn).exe` やそのショートカットを **Shift キーを押しながらダブルクリック**しても開けます。

- **歓迎の言葉**：あいさつと呼び名。アニメーションでの表示がその場で確認できます。
- **最後の声**：10 種類の声。▶ で試聴し、カードを押して選びます。声をオフにしたり、音量を変えたりもできます。
- **BGM**：オン／オフと音量。BGM と声の両方をオフにすると、完全に無音になります。
- **画面効果**：Live2D のスイッチと、動画の画質を選ぶ 2 つのドロップダウン：解像度（480p / 720p / 1080p / 2K）とフレームレート（30 / 60 fps）。既定は 1080p · 30 です（まだ作っていない画質はグレーになります）。Live2D オフのときは毛先のそよぎをオン／オフできます。落ち葉の多い／少ないも選べます。性能の低いパソコンでは下げられます。
- **キャラクター画像**：新しい版か元の版。
- **プレビュー**：保存前の設定でアニメーションを一度再生します（Claude は起動しません）。

`Claude (Dawn).exe` はこのパソコンの中だけで使う小さなサーバー（`localhost`、ポートはランダム）を立て、アニメーションも設定ページもそこから開きます：

- ファイルから直接開いたページはローカル動画のピクセルを読めませんが、`localhost` から開いたページは読めます。そのため、まばたきを再生中の Live2D 動画の上に描けます。`splash.html` を直接開いた場合も Live2D 動画は再生されますが、まばたきはしません。
- Web ページは自分でファイルを書けないため、保存するときは設定ページが（ランダムな合言葉を付けて）このプログラムに頼み、選んだ内容を `config.js` に書き込みます。

アニメーションや設定ウィンドウが閉じると、サーバーも止まります。

### 手で変更する（`config.js`）

設定ページが書き込むのはこのファイルで、テキストエディターで直接変更することもできます。すべての項目と既定値は `config.example.js` にあります：

| 項目 | 既定値 | 説明 |
|---|---|---|
| `name` | 空 | 歓迎の言葉に入る呼び名。空のときはあいさつだけを表示 |
| `greeting` | `欢迎回来` | あいさつ |
| `voice` / `voiceId` / `voiceVolume` | `true` / `sonia` / `1.0` | 最後の声、どの声を使うか（`tools\voices.json` の id）、音量 |
| `sound` / `volume` | `true` / `0.8` | BGM とその音量 |
| `art` | `new` | `new` = Inanis404 の新しい画像、`classic` = Firefade0329 の元の画像 |
| `liveVideo` | `1080p30` | Live2D：`off`（静止画。目はコマごとの合成で開く）または動画の画質 `480p30` … `1080p60`、`1440p30` / `1440p60`（2K） |
| `petals` / `hairSway` | `more` / `true` | 落ち葉の多さ（`more` / `less`）、毛先が風にそよぐかどうか（Live2D オフのときのみ） |
| `artRoot` | `third_party/claude-desktop-splash` | 元のプロジェクトの置き場所 |

ランチャーのオプションは元のプロジェクトと同じで（`-NoSound`、`-NoClaude`、`-Fullscreen`、`-Art new|classic` など）、`Claude (Dawn).exe` の後ろに付けて使えます。詳しくは `launcher\launch.ps1` の冒頭を見てください。

デバッグ用のページパラメーター：`?t=5.2` で指定の秒で止める、`?speed=0.5` でスロー再生、`?name=xxx` で呼び名を一時的に変える、`?voice=emma` で声を変える、`?novideo` で目の動画を使わない、`?novoice` で声を入れない、`?nosfx` で効果音を入れない、`?mute` ですべて消音、`?withvoice` で `config.js` で声をオフにしていても声を再生。`?renderaudio` と `?render`（`localhost` から開く）で音を WAV に、画面を 1 コマずつ書き出します（デモ動画づくり用）。`?track`（`localhost` から開く）で動画の各時刻の目の位置を測ります。結果は `js\splash.js` に組み込み済みです。

## 確認済みの範囲

- Edge のスクリーンショットで、各場面をコマ単位で確認しました。
- Claude を完全に終了してからダブルクリックする、本来の起動の流れは、まだ実際に動かして確認する必要があります。問題があれば `launcher\launcher.log` を見てください。
- `Claude (Dawn).exe` をアニメーションのみのモード（`-NoClaude`）で実際に動かし、Claude のウィンドウをぴったり覆って正常にフェードアウトすることを確認しました。
- **滑らかさの実測**（このパソコン：AMD Radeon 610M 内蔵 GPU、120Hz の画面、ウィンドウ 2300×1200、`localhost` から開き、すべてのコマの間隔を記録）：画面の上限は 60 fps です。声を再生した状態で測りました。25 ミリ秒を超える遅いコマの割合は、1080p · 60 で約 2〜3%（最初の版は約 35%。そのときのパソコンの忙しさで変わります）、Live2D オフで約 3.5%、2K · 60 で約 6〜7%（いちばん重い部分で 2K 動画がすでに再生されているため）です。Live2D モードでもカメラは最後までゆっくり寄り続けます。動画は WebGL のレイヤーに描いているので、それでカクつくことはありません。ほとんどの時間は、セリフの間も含めて安定した 60 fps で、最も重い 3.5〜6.5 秒（線画、にじみ、動画が重なる部分）は約 50〜53 fps です。にじみの夜色のマスクを独立した全画面レイヤーではなく動画のレイヤーの中で描くようにして、その部分の遅いコマが約 3 分の 1 減りました（交互に測って比較）。残っている遅いコマはほぼすべて 25〜29 ミリ秒（画面の更新 1 回分の遅れ）で、4.5〜6 秒と 7.5 秒付近にときどき出ます。8 種類の画質はすべて最後まで再生できます。
- **測れていないこと**：Claude 本体も GPU を使う、実際のコールドスタートは、ここでは確認できません。ここで測ったのはアニメーションだけを再生し、CPU 負荷で Claude の起動を模した場合です。
- **つながり**：実際の再生を画面録画し、1 秒 18 コマで 1 コマずつ確認しました（負荷なしの場合と、Claude の起動を模した 6 本の高負荷スレッドがある場合）。色が広がるあいだキャラクターが止まって見える（今は動画がにじみと同時に始まり、カメラもゆっくり寄り続け、光る線画は色が広がったところから消えるので、動いている絵の上に止まった線が残りません）、まばたきのあいだ目のまわりの前髪や肌が「止まる」（今はまばたきで実際に変わるまぶたと瞳だけを覆い、動画の中の頭のわずかな動きにも合わせて動きます）、最後に舞い落ちる葉が逆向きに飛ぶ（今は逆再生ではなくスローモーション）、そのスローモーションでキャラクターがカクカク動く（今は実際にポーズが変わるコマだけから補間）、120Hz の画面で 1 秒に約 3 回、動画のコマが飛んだり 2 回表示されたりする（60 fps の動画では、動画に新しいコマが来たときに描くようにしたので、どのコマもちょうど 1 回ずつ表示されます）、まばたきが速すぎて穏やかな雰囲気に合わない（今は 0.3 秒かけて閉じ、少し止まってから 0.5 秒かけてゆっくり開きます）、花びらが止まってから瞬間移動する、目を開けるのが遅れる（声のあとに開く）、光のリボンが急に消える、話す前に動画から静止画へ切り替わる（色が変わり、髪が急に止まる）、という問題を直しました。今は動画が最後まで再生され、まばたきは動画の上に描かれます。実際の起動経路（`Claude (Dawn).exe -NoClaude`、ページは `localhost` から）も同じ方法で録画して確認しました。
- 音はアニメーションの時計に合わせて鳴るので、画面が詰まったときは音楽と声も一緒に待ちます。
- 設定ページ：開く、声の一覧、プレビュー、`config.js` への保存、ウィンドウを閉じたあとのプログラムの終了を、実際に確認しました。
- 声がやさしく自然に聞こえるかどうかは、人の耳で判断する必要があります。設定ページで一つずつ聞き比べてください。
